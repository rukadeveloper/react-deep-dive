# [미션 2: 중급] 데이터 동기화를 해결한 프로 쇼핑 카트

### 1. 상세 시나리오 및 배경

배경: 장바구니의 모든 정보 (목록, 금액, 수량)을 하나의 리듀서에서 원자적으로 처리하여 데이터가 엉키는 것을 차단합니다.
목표: payload를 통해 외부 데이터를 리듀서로 전달하고, 객체와 배열이 포함된 복합 상태를 안전하게 불변성 유지하여 업데이트합니다.

### 2. 상세 구현 요구사항

상품 추가(ADD_ITEM)
- 컴포넌트에서 보낸 상품 객체(payload)를 기존 items 배열에 추가합니다.
- 이 때, totalPrice에는 추가된 상품의 가격을 더하고, totalQuantity는 1을 증가시킵니다.
- 이 변화들이 동시에 일어나야 합니다.

상품 삭제(REMOVE_ITEM)
- 삭제하려는 상품의 id를 payload로 받습니다.
- 먼저 find를 이용해 삭제될 상품이 무엇인지 찾아 가격 정보를 확보합니다.
- filter를 이용해 해당 상품만 제외된 새로운 배열을 만듭니다.
- 확보한 가격만큼 totalPrice에서 차감하고 totalQuantity에서 1을 감소시킵니다.

데이터 불변성 유지
- 상태를 업데이트할 때 기존의 state를 직접 수정하지 않고 반드시 스프레드 연산자 사용하여 새로운 객체를 반환합니다.

### 4. 데이터 흐름

사용자 클릭: 특정 상품 옆의 [삭제] 버튼을 누릅니다.
데이터 전달: dispatch를 통해 삭제할 아이디가 담긴 payload를 리듀서에 던집니다.
리듀서 연산: 리듀서는 전달받은 아이디로 목록을 필터링하고, 금액과 수량을 다시 계산합니다.
결과 반영: React가 변경된 단 하나의 상태 객체를 감지하고 UI를 다시 그립니다.
