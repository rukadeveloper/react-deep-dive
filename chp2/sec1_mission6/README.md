# [미션 6: 고급] 글로벌 교육 플랫폼 - 수강 바구니 시스템 아키텍처 구축

### 1. 상세 시나리오 및 배경

사용자가 강의를 장바구니에 담고 수량을 조절하거나 삭제할 수 있는 수강 신청 바구니 엔진을 만듭니다.
강의 데이터는 id, name, price, quantity를 가진 객체들의 배열로 관리됩니다.
단순한 로직이 아니라 수량이 1 미만으로 내려가지 않도록 막는 방어 로직과
모든 수치가 실시간으로 동기화되는 단방향 데이터 흐름을 완벽히 구현해야 합니다.

### 2. 구현 요구사항

1. 아키텍처 설계 : 로직 별로 파일을 분리합니다.

- courseTypes.js
- courseActions.js
- courseReducer.js

2. 정밀한 수량 제어

- + 버튼 클릭 시 해당 강의 수량 증가
- - 버튼 클릭 시 수량 감소하지만, 수량은 1보다 작아질 수 없습니다.

3. 강의 삭제

- 삭제 버튼 클릭 시 해당 강의를 목록에서 즉시 제거합니다.

4. 불변성 기반의 상태 업데이트

- 반드시 map과 filter 사용하여 새로운 배열을 반환하세요.
