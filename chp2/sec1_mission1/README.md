# [미션 1: 초급] 급식실 재고 관리 시스템 구현

### 1. 상세 시나리오 및 배경

배경 : 급식실 운영 매뉴얼(Reducer)를 만들어 상태 변경을 한 곳에서 처리하세요.
목표 : useReducer를 사용하여 상태 변경 로직(매뉴얼)과 UI(화면)을 분리하는 기초 구조를 마스터합니다.
시나리오
- 초기 밥 재고는 10인분입니다.
- 조리사가 밥 하기 버튼을 누르면 10인분이 추가됩니다.
- 배식 담당자가 배식하기 버튼을 누르면 1인분이 줄어듭니다.
- 비즈니스 규칙: 밥 재고는 0 미만으로 내려갈 수 없습니다. 0인분일 때 배식하기를 누르면, alert 창을 띄우고 상태를 변경하지 말아야 합니다.

### 2. 단계별 실습 가이드

Step 1 : src/components/Cafeteria.jsx 파일을 생성합니다.
Step 2 : 리듀서는 다음과 같은 함수로 동작합니다 -> (현재 상태, 요청서) => 새로운 상태
Step 3 : 세부 구현 요구사항
- 상태 구조 : { rice: 10 } 객체 형태를 유지하세요.
- 액션 정의 : COOK_RICE(밥 하기), SERVE_RICE(배식하기) 2가지 타입을 이용하세요.
- 방어 로직 : 리듀서 내부에서 SERVER_RICE 처리 시 현재 재고가 0인지 체크하는 조건문을 반드시 포함하세요.

### 4. 데이터 흐름

- 사용자 행동 : 배식하기 버튼 클릭
- Dispatch : dispatch({ type: 'SERVE_RICE'}) 호출 (요청서 제출)
- Reducer : 매뉴얼 확인 및 재고가 0보다 큰지 확인 -> state.rice - 1 반환
- Update : React가 새로운 상태를 받아 화면의 숫자 업데이트
