# [미션 3: 고급] 비즈니스 규칙이 담긴 '스마트 티켓 예매 시스템'

### 1. 상세 시나리오 및 배경

배경: 예매 시스템은 1인당 최대 4좌석까지만 예매 가능하고, VIP 등급은 즉시 20% 할인이 적용됩니다.
목표: 복잡한 조건문은 리듀서 내부에 작성하여, 컴포넌트는 오직 Dispatch만 내리고, 복잡한 계산은 Reducer가 전담합니다.

### 2. 상세 구현 요구사항

수강생 여러분은 다음 4가지 핵심 동작을 리듀서와 컴포넌트 내에 구현해야 합니다.

1. 좌석 토글(TOGGLE_SEAT)

- 사용자가 좌석 번호를 클릭하면 실행됩니다.
- 동작 A : 이미 선택된 좌석이라면, 목록에서 제거(취소)합니다.
- 동작 B : 새로 선택하는 좌석이라면, 목록에 추가하되, 최대 4개 제한 규칙을 확인합니다.
- 방어 로직: 이미 4개가 선택된 상태에서 5개째를 누르면 alert를 띄우고 상태를 변경하지 않습니다.

2. VIP 등급 전환(TOGGLE_VIP)

- 사용자의 등급을 [일반/VIP]로 전환합니다.
- 동작: VIP 상태가 true가 되면 즉시 결제 금액에 20% 할인이 적용되어야 하며, 다시 일반이 되면 원복됩니다.

3. 실시간 금액 계산

- 좌석 당 가격은 15,000원 입니다.
- 좌석이 추가/제거 되거나 등급이 바뀔때마다 totalAmount가 실시간으로 자동 계산되어야 합니다. (일반: 1.0 / VIP 0.8)

4. 액션 타입 상수화

- 오타 방지를 위해 const ACTION_TYPES = {} 객체를 만들어 사용합니다.

### 4. 데이터 흐름

1. 사용자 행동: [A3] 좌석을 클릭함.
2. dispatch({ type: 'TOGGLE_SEAT', payload: 'A3'}) 요청서 발송
3. Reducer 검증 : A3가 이미 리스트에 있는가? (있으면 제거)
4. Reducer 검증 : 현재 선택된 좌석이 4개인가? (4개면 추가 거부 및 alert)
5. Reducer 검증 : 위 조건 통과 시 좌석 추가 및 VIP 할인율을 반영한 금액 계산
6. Update: 화면의 좌석 색상과 결제 금액이 동시에 업데이트
